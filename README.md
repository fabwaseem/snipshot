# Snipshot (legacy)

> **This repository is the original Wails (v1) app and is no longer the primary release channel.**
>
> **Snipshot has been rebuilt** as a Tauri 2 desktop app with a new UI, mockups, Surprise Me looks, WebP export, and signed auto-updates.

## Get the new version

| | |
|---|---|
| **Download** | [github.com/fabwaseem/snipshot-releases](https://github.com/fabwaseem/snipshot-releases/releases) |
| **Latest installer** | See the newest release assets (Windows NSIS) |
| **Auto-updates** | Built into the new app after you install once |

```text
Old (this repo)     →  Wails + Go + React  (archived development)
New                 →  Tauri 2 + React     (current product)
Public binaries     →  fabwaseem/snipshot-releases
```

## What's new in the upgrade

- Faster native shell (Tauri 2) with tray + global hotkeys
- Mockup styles, shape/shadow scenes, noise, and size-aware padding
- Surprise Me looks matched to your screenshot colors
- Annotations, watermarks, and export to PNG / JPEG / WebP
- Signed auto-update from GitHub Releases

## This repo (v1)

Kept for history and reference only. Source here is the **Wails** build.

- Stack: Wails v2 · Go · React · html2canvas
- Last line of development: see commit history
- **Do not use these releases for new installs** — prefer [snipshot-releases](https://github.com/fabwaseem/snipshot-releases/releases)

If you still need a v1 binary for some reason, older assets may remain under this repo's [Releases](https://github.com/fabwaseem/snipshot/releases), but they are unsupported.
